# 阶段 3 交付记录

日期：2026-10-15。身份与知识库隔离实现及验收均完成，阶段 4 尚未开始。

## 实现范围

- 0002_identity_knowledge_bases 迁移：users、knowledge_bases、knowledge_base_members、authorization_guard；保留 0001 基线，无后续阶段业务表。
- 可信本机 CLI 创建、列表、停用/启用真实用户；Argon2id，密码交互或显式 stdin，不接收密码参数，无默认用户。
- JWT 固定 HS256/30 分钟、必要 claims/签名校验、每请求用户有效状态复核、单进程基本限流；安全错误、响应 no-store。
- 知识库与成员服务复用当前 MySQL 成员事实；列表隔离、角色边界、逻辑删除父资源检查、签名分页游标。管理员没有隐含库权限。
- 短事务先取得单行授权变更锁，再锁知识库、复核身份/角色与有效 owner；停用与移除/降级 owner 的竞争安全。哈希在事务外，读取不持全局授权锁。
- Vue 登录、创建/列表/详情/修改/删除、成员角色与移除页面；token 只存内存，401/退出取消旧请求，迟到结果不能污染新会话。服务状态页面保留。
- 同步接口契约、实际 OpenAPI、数据模型、配置生成/升级、Compose 与 README。

## 关键边界

授权写操作串行化适合当前小规模部署，未做吞吐/压力测试；未来优化锁粒度需保留并发不变量。基本限流只覆盖一个 API 进程，直接连接来源共享配额，不信任用户的转发头；重启清空。token 没有服务端逐个吊销或 refresh，启用用户后未过期的 token 可重新使用。
