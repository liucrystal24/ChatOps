# 六阶段增量开发规划

本文件为回溯整理的设计基线，阶段1不包含业务实现或测试通过声明。

| 阶段 | 目标 | 验收重点 |
| --- | --- | --- |
| 1 | 环境、架构、模型与接口设计 | 文档一致性及阶段边界 |
| 2 | 可运行工程骨架 | API、Web、真实依赖健康检查及持久化 |
| 3 | 身份与知识库隔离 | 登录、角色、越权及最后owner并发约束 |
| 4 | 文档索引与Dense检索 | 真实Embedding、租约、完整发布、来源定位和权限范围 |
| 5 | 多轮RAG闭环及质量修复 | SSE、引用、拒答、冻结题集与质量验收 |
| 6 | 检索优化对照实验 | Hybrid、Rerank等的质量、延迟和成本收益 |

每阶段按用户要求推进。API与Worker共用模块，关键规则用真实MySQL/Qdrant测试，不以测试替身充当运行服务；密钥来自环境变量。阶段6只有计划，不提前实现。
