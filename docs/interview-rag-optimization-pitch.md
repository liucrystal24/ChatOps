# RAG 优化：面试口述卡

对应当前代码，核对日期：2026-10-16。先不熟悉原理时，读[图文与代码讲解](interview-rag-optimization-guide.md)。

## 约一分钟的回答

> 我做的是一个带权限隔离的知识库问答系统。优化时先把错误分成三类：找不到证据、处理时丢掉证据、找到证据却回答错。
>
> 对找不到证据的问题，我调整了段落和列表切分，补全多轮追问，并针对表格做逐行向量表示。比如“owner导出通讯录还需要什么条件”，正确依据从第7提升到第2，能回答“需要二次确认”。
>
> 对已召回却答错的问题，我发现普通表格被证据处理代码漏掉，导致标准版问题答成专业版。修复表头与行绑定后，再约束套餐、年份、角色和所问属性；模型只选择证据编号，服务端校验并输出原文引用，避免日期、容量等事实被改写错。
>
> 最终，同口径原题集Recall@5从54.5%提高到95.45%；业务回归Agent评审从32/36提高到36/36，独立真人审核仍待完成。

## 只给30秒时

> 我通过固定测试集定位RAG错误，区分检索漏召回、证据处理丢失和生成误答。分别优化段落切分与追问改写、表格逐行索引，以及对象属性校验和原文引用输出。一个权限表问题的正确依据从第7提升到第2；原题集同口径Recall@5从54.5%提高到95.45%。我也单独检查答案正确性和拒答，避免只看召回率。

## 面试官追问时，补一句就够

| 追问 | 可以这样回答 |
| --- | --- |
| 最典型的代码问题？ | 标准版导出限额的正确表格已排第1，但处理代码只支持权限表，普通表格被丢了。补齐表格证据提取后，答案从专业版120,000行/4小时纠正为标准版12,000行/18小时。 |
| 表格逐行索引具体是什么？ | 检索向量编码目标行的“列名：值”和章节，减少其他行干扰；引用保留表头到目标行的连续原文和字符位置，派生文字不当作原文。代价是切片数42增至47。 |
| 如何防止模型乱答？ | 模型只选证据编号，服务端检查对象、属性、原文位置并输出摘录；无直接依据拒答。这降低了编造空间，但不能保证所有语义都正确。 |
| 为什么引用100%有效仍有错？ | 引用有效只说明来源可访问。例如问签约地点却引用签约日期，来源真实，答案仍不对。 |
| 测试依据是什么？ | 冻结题目和原文证据位置，跑真实服务；业务集五篇文章含不同套餐、年份、角色等干扰项。分别检查前五召回、证据目录、引用和答案。修复后题集只称回归。 |
| 主要指标有哪些？ | Recall@5定位漏召回；答案正确性与事实支持看答得对不对；正确拒答和误拒答防止乱答或过度拒答；引用有效性、权限隔离另外检查。 |
| 用了Multi-query、Rewrite、Rerank吗？ | 已做多轮追问的Query Rewrite，仍是单个Dense查询；Multi-query、Hybrid和Rerank还没实现。当前先修已定位的切分、表格和证据处理问题。 |
| 为什么不先换大模型？ | 部分错误来自确定的代码缺陷，例如正确表格被丢弃；先修这类问题。本轮没换模型，仍用bge-m3和Qwen3-8B，不据此推断模型能力没有影响。 |
| 做过无效尝试吗？ | 做过。额外模型充分性判断仍放过错误且误拒答，已撤回；整表字段化只把一个问题从第7提到第6，最终逐行表示才到第2。 |
| 为什么不报召回100%？ | 最新原题集旧口径是21/22，95.45%；扩展等价证据口径为41/41。分母和标注规则不同，我会分别报告。 |

讲述顺序记为：**一个错题 → 定位哪一环 → 代码改了什么 → 同口径结果 → 有什么边界。**

以上均为项目内回归结果。阶段5独立真人质量验收待完成；不能说真实业务准确率100%、已做独立盲测，或已经实施阶段6。
