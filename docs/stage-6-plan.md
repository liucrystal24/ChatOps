## 原规划与验收边界

- [ ] 引入真实 sparse 编码与中文分词，扩展 collection 并补索引；所有 prefetch 强制同一授权范围。
- [ ] Dense/sparse RRF Hybrid，对齐 Top-K、候选数量、过滤和评分解释。
- [ ] 真实 Rerank，候选量上限、timeout、可见降级与引用映射。
- [ ] 同一题集比较 Dense、Hybrid、Hybrid + Rerank；记录 Recall、MRR/nDCG、引用、拒答、耗时和调用开销。
- [ ] 只在验证质量收益和可接受延迟后调整默认策略；不以几个精选问题代替整体对比。

验收：无权限/已删除文档在每个召回分支和 Rerank 输入中均为零；真实优化实验可复现，失败/降级单独报告；未达质量或延迟目标则保留 Dense 默认并如实记录结果，不能硬宣称优化有效。
